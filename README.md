One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny.

`main.py` (stdlib only) writes the single line from `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it:

```sh
python3 -S main.py
```
